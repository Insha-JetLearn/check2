# AI Science Lab

## Build
- Replace the blank page with a responsive futuristic science dashboard using a dark cyan/purple lab visual system.
- Add seven navigable modules: Volcano, Electricity, Gravity, Rocket, DNA, Submarine, and Quiz Arena.
- Give each lab an interactive simulation with sliders or selectors, a simple live scientific result, a mini challenge, explanations, and a short quiz.
- Add shared XP, levels, badges, daily challenge progress, saved progress, sound feedback, and a floating assistant available throughout.
- Use a lightweight Three.js scene for the interactive 3D-style laboratory centerpiece, with accessible motion-reduction behavior and mobile controls.

## Technical details
- Build on the existing React/TanStack app and use semantic Tailwind design tokens.
- Keep progress on the learner’s device; no account or online backend is required.
- Use Web Audio for opt-in sound effects and Three.js through React Three Fiber for the central simulation visuals.
- Add app-specific page metadata and verify desktop/mobile rendering and every interactive control.
