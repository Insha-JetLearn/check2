# AI Science Nexus

Use this short prompt:

Build a futuristic interactive educational website called “AI Science Lab” for learners aged 12–14. Create a dark neon sci-fi lab design with glowing cyan/purple effects, animations, 3D-style visuals, and game-like interactions. Include a Home dashboard and fully functional modules: 🌋 Volcano Lab, ⚡ Electricity Lab, 🪐 Gravity Chamber, 🚀 Rocket Launch Bay, 🧬 DNA Mixing Center, 🌊 Submarine Lab, and 🏆 Quiz Arena. Each lab should have interactive controls, realistic simulations, educational explanations, mini challenges, quizzes, XP/badges, and progress tracking. Add a floating AI science assistant on every page. Include daily challenges, achievements, responsive mobile/desktop design, smooth animations, sound feedback, and no dead buttons. Keep science explanations accurate but simple and age-appropriate. Use HTML/CSS/JavaScript or React, with Three.js for 3D effects where useful. Make the UI feel like a premium futuristic NASA/STEM science museum game.
